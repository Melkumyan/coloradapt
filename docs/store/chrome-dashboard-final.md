# Chrome Web Store dashboard: final field values

Every dashboard field that can be written in advance. Format per field: **FIELD**, **FINAL VALUE**, **SOURCE**, and whether
the owner must verify it in the live dashboard. The dashboard's exact current wording could not be read without a developer
account, so category names and checkbox labels are marked `VERIFY_EXACT_UI_WORDING_AT_SUBMISSION`: answer by meaning, not by
matching these words. Nothing here has been submitted.

# Mozilla Add-ons: описание (русский)

Тот же функционал и те же оговорки, что в `firefox-listing.md`; ничего сверх него.

**Name:** ColorAdapt

**Summary:** Помогает людям с нарушением цветового зрения различать цвета на сайтах: адаптирует цвета страниц и добавляет нецветовые метки. Всё локально, без телеметрии.

## Описание

```text
ColorAdapt помогает людям с нарушением цветового зрения читать веб-страницы и различать используемые на них цвета.

Выберите профиль цветового зрения (протанопия, протаномалия, дейтеранопия, дейтераномалия, тританопия, тританомалия,
ахроматопсия или свой профиль). ColorAdapt оценивает, какие сочетания цветов текста и интерфейса трудно различить для
профиля, и меняет только их — на минимально необходимую величину. Выключите расширение — страница вернётся к виду,
заданному сайтом.

Что делает расширение
• Подстраивает трудноразличимые цвета текста и интерфейса, остальное не трогает.
• Добавляет небольшие нецветовые метки (галочку, крестик, контур), если состояние передано только цветом, а разметка
  страницы его ясно показывает.
• Помогает различать ряды на графиках стилем линии, маркерами и узорами (поддерживаемые SVG-графики).
• Адаптирует одноцветные значки (встроенный SVG и, по желанию, небольшие значки-изображения).
• Аудит для разработчиков: отчёт только для чтения о проблемах, связанных с цветом, с возможностью выгрузки.
• По желанию (выключено по умолчанию): ИИ-помощь при разборе замечаний аудита с языковой моделью на вашем компьютере.

Конфиденциальность
• По умолчанию ColorAdapt не отправляет данные страниц во внешние сервисы. Нет телеметрии, аналитики, рекламы, учётных
  записей. Настройки хранятся в браузере.
• ИИ-разбор выключен по умолчанию. Если вы его запустите, ColorAdapt может отправить небольшое обезличенное смысловое
  описание на локальный ИИ-сервер (loopback) на вашем компьютере. Firefox сначала запросит ваше разрешение (необязательное
  разрешение «содержимое сайтов»); вы можете отозвать его в любой момент, без него ничего не отправляется. Облачного
  резервного варианта нет, модель в расширение не входит.

Важно
• Адаптация — оценка на основе распространённых моделей цветового зрения; это не медицинский инструмент, он не
  восстанавливает цветовое зрение.
• Сложная графика и часть страниц могут остаться без изменений, часть случаев оставлена для ручной проверки. ColorAdapt не
  делает страницу соответствующей WCAG.
• Интерфейс пока только на английском языке.
• Нужен Firefox 140 или новее и доступ к сайтам, чтобы их адаптировать.
```

**Notes for reviewers:** на английском, как в `firefox-listing.md`.

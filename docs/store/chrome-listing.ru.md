## Вкладка Store listing

**Name:** ColorAdapt

**Summary:** Помогает людям с нарушением цветового зрения различать цвета на сайтах: адаптирует цвета страниц и добавляет нецветовые метки.

**Category:** Accessibility (проверить по списку в панели при отправке)

**Language:** Русский (интерфейс расширения пока только английский)

**Detailed description:**

```text
ColorAdapt помогает людям с нарушением цветового зрения читать веб-страницы и различать используемые на них цвета.

Выберите профиль цветового зрения (протанопия, протаномалия, дейтеранопия, дейтераномалия, тританопия, тританомалия,
ахроматопсия или свой профиль). ColorAdapt анализирует цвета открытой страницы, оценивает, какие сочетания цветов текста
и элементов интерфейса трудно различить для выбранного профиля, и меняет только их — на минимально необходимую величину.
Выключите расширение — и страница вернётся ровно к тому виду, который задал сайт.

Что делает расширение
• Подстраивает цвета текста и интерфейса, которые трудно различить для вашего профиля; остальное не трогает.
• Добавляет небольшие нецветовые метки (галочку, крестик, знак предупреждения), если состояние передано только цветом,
  а разметка страницы это состояние ясно показывает.
• Помогает различать ряды на графиках: стиль линии, маркеры и узоры в поддерживаемых SVG-графиках.
• Адаптирует одноцветные значки (встроенный SVG и, по желанию, небольшие значки-изображения).
• Аудит для разработчиков: отчёт только для чтения о проблемах, связанных с цветом, с доказательствами; его можно
  выгрузить.
• По желанию (выключено по умолчанию): ИИ-помощь при разборе замечаний аудита, требующих решения человека, с
  использованием языковой модели, работающей на вашем компьютере.

Конфиденциальность
• По умолчанию ColorAdapt не отправляет данные страниц во внешние сервисы. Нет телеметрии, аналитики, рекламы и учётных
  записей.
• Настройки хранятся в вашем браузере.
• Необязательный ИИ-разбор для разработчиков выключен по умолчанию. Если вы включите и запустите его, ColorAdapt может
  отправить небольшое обезличенное смысловое описание на локальный ИИ-сервер (loopback) на вашем компьютере, например
  Ollama. Облачного резервного варианта нет; нужен отдельно установленный локальный сервер.

Важно
• Адаптация — оценка на основе распространённых моделей цветового зрения. Это не медицинский инструмент, он не
  восстанавливает цветовое зрение и не заменяет консультацию специалиста.
• Сложная графика и часть страниц могут остаться без изменений, а некоторые случаи оставлены для ручной проверки.
  ColorAdapt не делает страницу соответствующей WCAG.
• Интерфейс пока только на английском языке.
• ColorAdapt нужен доступ к сайтам, чтобы их адаптировать.
```

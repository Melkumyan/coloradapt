# Reference tooling (development only)

`generate_reference.py` regenerates the Machado 2009 matrix table and the
cross-validation vectors from an independent implementation (DaltonLens). It
is not part of the extension and adds no runtime dependency. See the script's
docstring for the pinned commit and the known issues of the reference
implementation, and `docs/COLOR_VISION_SIMULATION.md` for context.
